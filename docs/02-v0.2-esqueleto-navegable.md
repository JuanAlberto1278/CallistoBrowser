# Callisto V0.2 — Esqueleto navegable

> Fecha: 2026-11-21 · Electron 45.4.1 (Chromium 156) · Estado: **completa, pendiente de tu revisión**

## Qué incluye

| Funcionalidad | Detalle |
|---|---|
| Ventana con una pestaña | Interfaz arriba (sesión interna propia) y la página debajo (sesión del perfil) |
| Barra de direcciones | Distingue URL de búsqueda; `ejemplo.com` va por HTTPS, con vuelta a HTTP si el sitio no lo ofrece (como Chrome); IP y `localhost` por HTTP; rutas `C:\…` como archivo; `javascript:`, `data:` y otros esquemas peligrosos se tratan como búsqueda |
| Búsqueda | Google (`https://www.google.com/search?q=…`). Configurable en una versión futura |
| Navegación | Atrás, adelante, recargar (Shift/Ctrl+clic: sin caché), detener |
| Indicador de carga | Barra animada bajo la barra de herramientas; recargar ↔ detener |
| Indicador de seguridad | Candado (HTTPS), "No seguro" (HTTP), "Archivo", error |
| Páginas de error propias | En español, con la URL y el código; se conserva la URL fallida en la barra y en el historial |
| Certificados inválidos | Bloqueados **sin opción de continuar** |
| Ventanas nuevas | `target=_blank` y `window.open` abren una ventana de Callisto, conservando `window.opener` (necesario para los popups de inicio de sesión) |
| Atajos | Ctrl+L / Alt+D / F6 (barra), Alt+←/→, F5 / Ctrl+R, Ctrl+F5 / Ctrl+Shift+R / Shift+F5 (sin caché), Esc (detener), F12 / Ctrl+Shift+I (herramientas de desarrollo), Ctrl+W (cerrar ventana) |
| URL por línea de comandos | `Callisto.exe https://…` abre esa dirección (base para "navegador predeterminado") |
| Instancia única | Abrir Callisto otra vez enfoca la ventana existente o abre la URL recibida en una ventana nueva |

### Decisiones de V0.1 aplicadas desde el inicio
- **User-agent honesto** `… Callisto/0.2.0 Chrome/156… Safari/537.36` (nunca disfrazado de Chrome).
- **Corrección de passkeys** en todas las páginas y iframes: no aparece solo el diálogo de llave USB.
- **Cookies cifradas en disco** (fuse `EnableCookieEncryption`, verificado en el ejecutable: prefijo `v10`).
- **Cuarentena privada de descargas**: la carpeta de descargas de la app apunta a `%APPDATA%\Callisto\Quarantine`.

## Seguridad

- Todas las páginas en **sandbox**, con `contextIsolation`, sin Node, sin `<webview>`, diálogos protegidos contra spam.
- La interfaz se sirve por `callisto://ui/` **solo en su sesión interna**; las páginas web no pueden navegar a ella ni pedirla
  (verificado), y no ven ninguna API de Callisto.
- IPC: cada mensaje se acepta solo si viene del frame principal de la interfaz de una ventana conocida; los argumentos se
  validan (tipo y largo).
- CSP estricta en la interfaz (`script-src 'self'`, `connect-src 'none'`, etc.).
- **Permisos**: cámara, micrófono, ubicación, notificaciones, dispositivos y el resto se **deniegan**. Solo se permiten
  pantalla completa, escritura sanitizada al portapapeles y bloqueo del puntero. (Electron, por defecto, los concede todos.)
- **Descargas**: todavía no hay gestor (V0.5). Toda descarga se cancela de inmediato, se avisa y no se guarda nada (verificado).
- Fuses del ejecutable: `RunAsNode`, `NODE_OPTIONS` y los argumentos de inspección desactivados; integridad del asar y carga
  solo desde el asar activadas; sin privilegios extra para `file://`.

## Estructura

```
src/
  main/        index (arranque) · window (ventana) · tab (pestaña) · profile (sesión/permisos/descargas)
               ipc (validación) · internal-protocol (callisto://) · shortcuts · error-page · paths
  preload/     ui.ts (API mínima para la interfaz) · web-content.ts (corrección WebAuthn, sin API)
  renderer/    interfaz en React (barra de herramientas, barra de direcciones, avisos)
  shared/      lógica pura: omnibox, seguridad de URL, user-agent, errores de red, contrato IPC
tests/
  unit/        Vitest
  e2e/         Playwright + Electron (perfil temporal y servidor local)
```

Las piezas están pensadas para que V0.3 agregue varias pestañas por ventana (`Tab` ya es independiente de la ventana) y
V0.7 varios perfiles (`Profile` ya encapsula la sesión).

## Cómo usarlo

```powershell
npm run dev
```
Modo desarrollo con recarga de la interfaz. Usa el perfil `%APPDATA%\Callisto-Dev`, separado del real y **sin cookies cifradas** porque los fuses solo se aplican al empaquetar.

```powershell
npm run package:dir
```
Genera `dist\win-unpacked\Callisto.exe`, el ejecutable con fuses. Perfil: `%APPDATA%\Callisto`.

```powershell
npm run check
```
Corre tipos, pruebas unitarias y end-to-end.

## Pruebas

| Tipo | Resultado |
|---|---|
| TypeScript (estricto) | sin errores |
| Unitarias (Vitest) | **64/64** — barra de direcciones (URL vs búsqueda, IPs, archivos, esquemas peligrosos), seguridad, user-agent, errores, atajos |
| End-to-end (Playwright) | **17/17** — ver lista abajo |
| Ejecutable empaquetado | arranca con URL por línea de comandos, user-agent `Callisto/0.2.0`, título correcto, cierre ordenado, fuses verificados, cookie cifrada `v10` |

End-to-end: arranque, navegación por URL, atrás/adelante (botones y teclado), recargar (botón, F5, Ctrl+R), indicador de
carga y detener (botón y Esc), búsqueda, página de error, puerto bloqueado, atajos de la barra, ventanas nuevas con
`window.opener`, descarga bloqueada sin archivos, user-agent, permisos denegados, corrección de passkeys, aislamiento de la
interfaz, HTTPS real y certificado inválido (estas dos requieren Internet y se saltan sin conexión).

Nota técnica: las teclas simuladas por Playwright no pasan por el evento que usa Callisto para los atajos; las pruebas
usan `webContents.sendInputEvent`, que recorre el mismo camino que una tecla real.

## Limitaciones conocidas

| Limitación | Cuándo se resuelve |
|---|---|
| Una pestaña por ventana; `target=_blank` abre una ventana nueva | V0.3 |
| Sin buscar en la página (Ctrl+F) ni zoom | V0.3 |
| Sin menú contextual al hacer clic derecho en la página | **propuesta: V0.3** |
| Los permisos se deniegan sin preguntar (videollamadas, mapas con ubicación y notificaciones no funcionan) | **propuesta: V0.4**, con decisiones guardadas por sitio |
| Sin sugerencias en la barra de direcciones | V0.4 (historial) |
| No recuerda tamaño ni posición de la ventana | V0.4 |
| Buscador fijo (Google) | V0.4 (configuración) |
| Descargas bloqueadas | V0.5 |
| Ícono de Electron por defecto, sin instalador ni firma | V1.0 |
| `npm audit`: 6 vulnerabilidades moderadas en `minimatch` dentro de electron-builder (herramienta de empaquetado, no va dentro de Callisto) | seguimiento |
